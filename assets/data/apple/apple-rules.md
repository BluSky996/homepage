# 判定规则说明（成熟 / 未熟 / 烂坏）

> **重要：这是“颜色特征 + 阈值规则”的分类实验，不是神经网络模型训练。**
> 项目里没有模型权重文件，也没有训练过程；下面的阈值直接来自原项目脚本中的规则。

## 输入特征（每个标注框内的 ROI 像素统计）

| 特征 | 计算方式 | 含义 |
|---|---|---|
| `brightness` | `(R_mean + G_mean + B_mean) / 3` | 区域整体亮度（0–255） |
| `RG_ratio` | `R_mean / (G_mean + 1e-6)` | 红色相对绿色的比例（越红越大） |
| `RB_ratio` | `R_mean / (B_mean + 1e-6)` | 红色相对蓝色的比例（展示参考） |

## 判定规则（原始脚本中的真实阈值）

```
if brightness >= 135 and RG_ratio >= 1.55:  → 成熟
elif brightness <= 95:                      → 未熟
else:                                       → 烂坏
```

- **成熟**：够亮且明显偏红；
- **未熟**：亮度过低（暗）；
- **烂坏**：介于两者之间（偏暗红/褐）。

## 另外两种阈值来源（测试预测入口使用）

1. **训练集自动阈值**：取类别均值的中点（成熟↔烂坏、烂坏↔未熟），再用测试图分位数（b90 / r30）微调成熟阈值；
2. **测试图动态阈值**：找不到可用训练特征时，用测试图自身的 `b80 / b50` 加固定 `RG 1.35 / 1.45`。

## 已知局限

- 只使用 RGB 均值，受光照、白平衡、拍摄设备影响较大；
- 训练样本仅 68 个框 / 8 张图，且类别不均衡（烂坏 43、成熟 13、未熟 12）；
- 规则阈值不是学习出来的，泛化能力有限。
